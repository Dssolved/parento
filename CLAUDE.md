## Проект

Parento — русскоязычная freemium веб-платформа для будущих и молодых родителей: курсы и уроки,
выстроенные в маршрут от планирования беременности до первого года ребёнка.

Ключевая фича — **адаптивная персонализация по неделям**: пользователь указывает ПДР или дату
рождения малыша, платформа считает текущую «неделю» и показывает актуальные для этого срока курсы.
Позиционирование: *трекер говорит, ЧТО происходит; Parento говорит, ЧТО ДЕЛАТЬ.*

Язык интерфейса и документации — русский. Код и коммиты — на английском.

## Стек

React 19 · Vite 6 · TypeScript 5.8 · TailwindCSS 3 · react-router-dom 6 · TanStack Query v5 ·
Supabase (Postgres + Auth) · Vercel · oxlint (не ESLint) · lucide-react.

Тестового фреймворка **нет**. Проверки перед коммитом:

```bash
npx tsc -b
npm run lint
npm run build
```

## Что важно знать сразу

- **Миграции применяются вручную** через Supabase SQL Editor. Часть из них, вероятно, ещё не
  накатана на боевую базу — проверочный запрос есть в `docs/current-state.md`. Новый код,
  зависящий от новой таблицы или колонки, должен деградировать мягко, а не падать.
- **RLS включена не везде.** У `profiles`, `courses`, `lessons`, `progress` её нет, поэтому
  Premium-гейт и `PrivateRoute` — это UX, а не безопасность. Не выдавать текущую защиту за
  надёжную и не строить на ней ничего денежного, пока RLS не закрыта.
- **`schema.sql` — базовая схема без миграций.** Для новой БД нужен `schema.sql` плюс все `add-*.sql`.
- Логику по возможности выносить в чистые функции в `src/lib/*`: страницы за авторизацией
  ассистент проверить в браузере не может, а чистые функции проверяются отдельно.
- Русские числительные склонять через `src/lib/pluralize.ts`, а не строковыми литералами.
- Каждая новая таблица получает `*Insert`-тип в `src/types/database.ts` и упоминание в `README.md`.

## Соглашения

- Новая миграция — отдельный файл `supabase/add-<фича>.sql`, по возможности идемпотентный,
  плюс запись в `README.md` и `docs/supabase-migrations.md`.
- Страницы подключаются лениво через `lazy()` в `src/App.tsx`.
- Файл `.claude/launch.json` (превью-сервер на порту 5199) намеренно не коммитится.
- Коммиты в `main`, деплой на Vercel автоматический.
