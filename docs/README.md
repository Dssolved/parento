## Быстрые факты

- Стек: React 19 + Vite + TypeScript + TailwindCSS 3 + TanStack Query v5 + Supabase + Vercel.
- Главная фича: адаптивная персонализация курсов по неделе беременности / возрасту малыша.
- Тестового фреймворка нет. Проверки: `npx tsc -b`, `npm run lint`, `npm run build`.
- Миграции применяются вручную через Supabase SQL Editor, автоматики нет.
- Два самых важных незакрытых вопроса: непримененные миграции и отсутствие RLS на основных
  таблицах — оба описаны в [current-state.md](./current-state.md).
